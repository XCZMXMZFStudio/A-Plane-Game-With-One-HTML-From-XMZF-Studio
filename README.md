XMZFgAme - Era of Aircraft Disintegration

A single-file HTML 3D aerial combat shooter game developed using Three.js.

Game Description
Pilot a fighter jet through endless airspace on critical missions. Destroy enemy aircraft, ground armored targets, and anti-aircraft batteries to accumulate points and achieve victory. The game's defining feature is its "disintegration" mechanics, realistically depicting the destruction of both player and enemy units upon being hit.

Controls
PC:

Mouse movement: Control flight orientation

Left mouse button: Fire

W / S keys: Increase or decrease throttle

Mobile:

Left virtual joystick: Control flight orientation

Right virtual button: Fire

Bottom throttle slider: Adjust speed

Game Objectives

Shoot down red enemy planes: +2 points

Destroy green armored vehicles: +5 points

Neutralize gray AA guns: +6 points

Reach 60 points to win.

Key Mechanics

Health Bar: Top-screen segments indicate player health, depleted by enemy fire or flak clouds.

Stall Gliding: Below critical speed, the plane enters a glide and rapidly loses altitude.

Collision Damage: Hitting any enemy unit (including AA guns or vehicles) instantly triggers disintegration and game over.

AA Gun Threat: Ground-based cannons predict player trajectories and fire explosive shells that create lethal flak clouds.

Technical Highlights

Built with Three.js (r128) for 3D rendering

Self-contained HTML file with bundled CSS/JS for instant play

Dual-platform support (PC + mobile)

Dynamic lighting, particle effects, and basic physics simulation
